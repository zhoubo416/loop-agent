# Design

本目录存放项目、子项目和组件的设计文档,描述结构、职责、接口和关键取舍。修改相关范围前必须先阅读对应设计。

- 仓库整体设计以及跨多个子系统的设计直接放在本目录。
- 每个子系统或组件自己的设计放在 `docs/design/<name>`。
- 一份设计涉及同级多个子系统或组件时,放在这些范围最近的共同上级目录,不任意归到其中一个。
- 大型设计的 `README.md` 是该范围的目录,先读入口再按任务读章节;存在明确阅读顺序时章节文件用两位数字开头,例如 `00-system-design.md`。
- 设计文档使用稳定的语义化路径,文件名用英文和连字符,不用日期命名。
- 只有设计文档写"修改历史",按日期倒序记录影响设计含义、边界或行为的重要变化,措辞和格式调整不记录。
- 文档索引由根 `AGENTS.md` 的 Design 索引维护,新增或移动设计文档时同步更新。

- `02-database-design.md` — 数据库表结构、字段和关系。

- `07-agent-engine-adapter.md` — Agent Engine Adapter 设计。
